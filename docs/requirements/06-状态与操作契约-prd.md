# 企业研发协作与交付管理平台｜状态与操作契约

## 交付候选的生命周期

拟定→范围冻结→测试中→待审批→已上线→签收。修订标准或制品后建立后继候选；原报告可查。

## 权限与操作者

产品经理定基线，工程师关联提交，测试人员复测，发布经理管理环境，业务代表签收授权范围。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 输入需求变更、基线与理由，返回受影响的标准、任务、测试和签收项，缺关联项须显式标记。
2. 发布请求固定候选、制品与目标环境。返回部署号及查单入口；回滚关联上一次获准且实际可用的制品。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 项目与需求基线 | 确定产品负责人和业务签收人，冻结范围时记录每条验收标准摘要；修订保留前后差异。 | 直接编辑冻结条款须走变更评审。 |
| 变更与迭代 | 变更沿需求到任务与测试传播，依赖带责任人和截止时间，计划冲突列出受影响迭代。 | 循环依赖须消除后才能排期。 |
| 研发协作 | 任务绑定仓库和提交身份，强制更新分支产生新快照，外部回执校验来源与提交。 | 迟到的旧提交成功回调不能标绿新构建。 |
| 测试与缺陷 | 用例关联标准版本，每次执行固定构建摘要与环境；失败可生成缺陷，关闭需复测依据。 | 另一构建的通过记录不能满足本候选门槛。 |
| 候选与制品 | 候选清单绑定提交、制品哈希、需求基线和必过测试集。热修从生产基点单建候选。 | 替换制品后撤销旧批准，要求重新核验。 |
| 发布与回滚 | 开发、预发、生产逐级校验同一摘要，部署工具执行外部动作，平台记录结果未知并支持查单。 | 流水线超时但实际已成功，查单后只确认一次。 |
| 验收与交付 | 业务方核对标准逐项签收，未通过项须有具名豁免和期限；冻结报告反查至提交与测试结果。 | 仍有无豁免阻断项则无法归档。 |
| 项目运营 | 按里程碑显示阻塞与待签，区分开发耗时和等待测试，人员移交保存历史责任人。 | 外部验收人仅能查看指定交付包。 |

## 失联、中断及恢复

冻结候选时绑定基线、制品摘要和门禁集；回执按提供方、运行 ID、提交匹配。生产发布按环境与请求号去重。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

缺测试覆盖与测试失败分别展示；紧急豁免写明签署人、理由、受影响标准和补验期限。 R1 保留旧证据，C2 的测试需在 H2 上重新通过；C1 可引用有效需求证据，涉及构建行为的门禁仍须满足 H2 的要求。
